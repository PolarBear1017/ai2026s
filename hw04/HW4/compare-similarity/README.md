# Compute Similarity
## 🔆 啟動與進入專案
### 1. 啟動虛擬環境
```
conda activate fontenv
```
### 2. 下載專案
```
git clone https://github.com/lctung/compare-similarity.git
```
### 3. 移動至專案目錄
```
cd D:\NTUT\AI\Font-Project\compare-similarity
```
### 4. 安裝套件 (只有第一次執行需要)
```
pip install -r requirements.txt
```
### 5. 計算 SSIM & LPIPS
```
python c1_excel.py
```

### 6. 繪製圖表
```
python c2_plot.py
```
